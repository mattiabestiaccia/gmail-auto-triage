**gmail.py** — Gmail API wrapper module:

`fetch_unread_ids(service, max_results: int = 100, after_date: str | None = None) -> list[str]`:
- Uses `service.users().messages().list(userId="me", q=query, maxResults=min(max_results, 500))`.
- Build query: start with `"is:unread"`. If `after_date` is provided (format "YYYY/MM/DD"), append `" after:{after_date}"` for rough pre-filtering (belt-and-suspenders per RESEARCH.md open question #2).
- Paginate using `list_next()` pattern from RESEARCH.md Pattern 2.
- Stop collecting when `len(ids) >= max_results`.
- Return list of message IDs.

`fetch_messages_batch(service, message_ids: list[str], on_progress: Callable[[int, int], None] | None = None) -> tuple[list[dict], list[tuple[str, Exception]]]`:
- Fetch message metadata in batches of 100 using `service.new_batch_http_request()` (RESEARCH.md Pattern 3).
- Request `format="metadata"` with `metadataHeaders=["From", "Subject", "Date"]`.
- Callback collects results and errors separately.
- After each batch of 100, call `on_progress(len(results), len(message_ids))` if provided (feeds the progressive counter).
- Return tuple of (results list, errors list).
- CRITICAL (FETCH-05): This function ONLY uses `messages.list` and `messages.get`. It MUST NOT call `messages.modify`, `messages.trash`, `messages.delete`, or any other mutating method. Add a comment at the top: "# SAFETY: This module ONLY reads. No modify/trash/delete calls."

`parse_message(msg: dict, snippet_length: int = 500) -> EmailData`:
- Extract headers from `msg["payload"]["headers"]` into a dict.
- Get `From`, `Subject`, `Date` from headers (default to empty string).
- Get `snippet` from `msg["snippet"]` and truncate to `snippet_length` characters (FETCH-04).
- Get `id`, `threadId`, `labelIds` from message.
- Return `EmailData` instance.

`filter_by_window(emails: list[EmailData], messages_raw: list[dict], hours: int = 24) -> list[EmailData]`:
- Calculate cutoff timestamp: `datetime.now(timezone.utc) - timedelta(hours=hours)`.
- Convert to epoch milliseconds.
- Filter using `internalDate` field from raw messages (precise filtering per RESEARCH.md open question #2).
- Return filtered list of EmailData.

**cli.py** — Main CLI module orchestrating config -> auth -> fetch:

`main(args: list[str] | None = None) -> None`:

1. **Parse arguments** using `argparse`:
   - `--config` / `-c`: path to categories.yaml (default: `"categories.yaml"`).
   - `--credentials`: path to credentials.json (default: `"credentials/credentials.json"`).
   - `--token`: path to token.json (default: `"credentials/token.json"`).
   - `--verbose` / `-v`: enable verbose output.
   - `--max-emails`: override max_emails from config (optional).
   - `--window-hours`: override processing_window_hours from config (optional).

2. **Load config** — call `load_config(args.config)`. Print info: "Loading config from {path}..." then success: "Loaded {N} categories: {names}".

3. **Authenticate** — call `authenticate(args.credentials, args.token)`. Build Gmail service with `get_gmail_service(creds)`. Print success: "Connected to Gmail."

4. **Calculate time window** — use `args.window_hours` if provided, otherwise `config.fetch.processing_window_hours`. Calculate `after_date` string for Gmail query (format "YYYY/MM/DD").

5. **Fetch unread IDs** — call `fetch_unread_ids(service, max_results=effective_max, after_date=after_date)`. Use `args.max_emails` if provided, otherwise `config.fetch.max_emails`. Print info: "Fetching unread emails (window: {hours}h, max: {max})..."

6. **Handle empty result** — if no IDs found, print success: "No unread emails found in the last {hours} hours." and return cleanly.

7. **Fetch message metadata** — call `fetch_messages_batch(service, ids, on_progress=lambda cur, tot: print_progress(cur, tot))`. Print progress during fetch.

8. **Parse and filter** — parse each raw message with `parse_message(msg, config.fetch.snippet_length)`. Filter by time window with `filter_by_window(emails, raw_messages, hours)`.

9. **Print compact summary** (per user decision):
   ```
   --- Summary ---
   Fetched: 42 emails
   After time filter: 38 emails
   Errors: 0
   Elapsed: 3.2s
   ```
   Use ANSI colors. Track elapsed time with `time.monotonic()`.

10. **Print email preview** (if `--verbose`): for each email, print sender, subject, snippet preview (first 80 chars).

Error handling:
- Wrap the entire pipeline in try/except.
- `KeyboardInterrupt` -> print "Interrupted." -> `sys.exit(130)`.
- `google.auth.exceptions.RefreshError` -> `print_error("Token refresh failed", suggestion="Delete {token_path} and re-run to re-authenticate")` -> `sys.exit(1)`.
- Other exceptions -> `print_error(str(e), suggestion="Run with --verbose for details")` -> `sys.exit(1)`.

from email_triage.cli import main

This allows running with `python -m email_triage`.
