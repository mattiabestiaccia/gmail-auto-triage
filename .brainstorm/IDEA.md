# Gmail Auto-Triage

> Uno script standalone che categorizza automaticamente le email Gmail non lette applicando etichette, usando un LLM leggero per la classificazione, eseguibile via cron senza intervento manuale.

## Il Problema

Le email si accumulano nella inbox senza alcun ordine. Lavoro, pubblicità, notifiche e altro finiscono tutti nello stesso posto, costringendo a uno smistamento manuale ogni volta che si apre Gmail. Non esiste una separazione strutturale tra ciò che è urgente e ciò che può aspettare.

## L'Approccio

Uno script shell che si collega a Gmail via API, legge le email non lette, le passa a un LLM leggero (Gemini Flash) per la categorizzazione, e applica le label corrispondenti direttamente in Gmail. Lo script gira via cron — mattina o sera — così la inbox è già organizzata quando viene aperta.

Il comportamento è strettamente conservativo:
- **Mai segnare come letto.** Lo script tocca solo le label, non lo stato di lettura. Le email restano non lette finché l'utente non le legge.
- **Mai archiviare.** Nessuna email viene rimossa dalla inbox. Le label servono come layer organizzativo, non come filtro distruttivo.
- **Mai agire senza conferma** per operazioni distruttive. Il tool categorizza, l'utente decide.

## Le Categorie

Le categorie iniziali sono da definire analizzando la inbox reale. Alcune già emerse:
- **Lavoro** — email professionali, da gestire in giornata.
- **Pubblicità** — newsletter, promo, offerte. Si accumulano e vengono visionate in batch ogni 2-3 giorni.
- Altre categorie emergeranno dall'analisi della inbox.

Non esiste logica di priorità nel codice. Le categorie sono puramente organizzative — la priorità è una decisione umana.

## Scelte Architetturali

- **Script standalone, non integrazione Claude.** L'obiettivo è indipendenza: niente sessione Claude da aprire, niente token da consumare per un'operazione ripetitiva. Lo script vive da solo.
- **Gemini Flash per la categorizzazione.** Modello veloce, economico, più che sufficiente per classificare email. Non serve un modello pesante per questo task.
- **Cron per l'automazione.** Zero frizione quotidiana: configuri una volta, ogni giorno trovi la inbox già ordinata.

## Flusso d'Uso

1. Il cron lancia lo script (es. ogni mattina alle 7).
2. Lo script si connette a Gmail, recupera le email non lette.
3. Ogni email viene passata a Gemini Flash con il prompt di categorizzazione.
4. Le label vengono applicate in Gmail.
5. L'utente apre Gmail e trova tutto organizzato per etichetta.

## Semi per il Futuro

- Potenziale prodotto per altri utenti, se funziona bene per uso personale.
- Possibilità di aggiungere azioni post-triage (archiviazione, risposte rapide) con conferma utente.
- Le categorie potrebbero evolversi nel tempo in base ai pattern della inbox.
