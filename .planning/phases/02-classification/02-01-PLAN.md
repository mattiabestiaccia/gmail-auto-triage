    Core behaviors to test (pure logic, no API mocking needed):

    1. fuzzy_match_category("Newsleter", ["Newsletter", "Finance", "Social"]) -> "Newsletter"
    2. fuzzy_match_category("totally_unknown", ["Newsletter", "Finance"]) -> None
    3. fuzzy_match_category("newsletter", ["Newsletter", "Finance"]) -> "Newsletter" (case insensitive)

    4. Confidence filtering: given ClassificationResult with categories [(cat="Newsletter", conf=0.8), (cat="Finance", conf=0.3)], threshold=0.5 -> only "Newsletter" survives
    5. Confidence filtering: both below threshold -> result maps to ambiguous
    6. Confidence filtering: both above threshold -> both survive (multi-label)

    7. build_classification_prompt includes category names, descriptions, examples from config
    8. build_classification_prompt includes email sender, subject, snippet

    9. Config extension: ClassificationConfig with confidence_threshold=0.5 default, model="gemini-2.5-flash" default
    10. Config extension: categories.yaml can include classification section

    API-level behavior (mocked):
    11. classify_email calls Gemini with Pydantic response_schema and temperature=0.1
    12. classify_email returns ClassificationResult with categories and reasoning
    13. classify_email applies fuzzy matching to LLM-returned category names
    14. classify_email filters by confidence threshold
    15. classify_email returns ambiguous result when all categories below threshold

    Cases:
    - fuzzy_match_category("Newsltter", valid_cats, threshold=70) -> "Newsletter"
    - fuzzy_match_category("xyz", valid_cats, threshold=70) -> None
    - apply_threshold([(Newsletter, 0.9), (Finance, 0.3)], threshold=0.5) -> [(Newsletter, 0.9)]
    - apply_threshold([(Newsletter, 0.2), (Finance, 0.3)], threshold=0.5) -> [] (-> ambiguous)
    - apply_threshold([(Newsletter, 0.9), (Finance, 0.7)], threshold=0.5) -> [(Newsletter, 0.9), (Finance, 0.7)]
  </behavior>
  <implementation>
    **Step 1: Install dependencies**
    ```bash
    uv add google-genai rapidfuzz
    ```

    **Step 2: Extend models.py**
    Add `CategoryClassification` (Pydantic BaseModel with `category: str` and `confidence: float`) and `ClassificationResponse` (Pydantic BaseModel with `categories: list[CategoryClassification]` max_length=2 and `reasoning: str`). These are Pydantic models because they serve as GenAI `response_schema`. Also add a plain dataclass `ClassificationResult` with `categories: list[tuple[str, float]]`, `reasoning: str`, `is_ambiguous: bool` -- this is the internal representation after fuzzy matching and threshold filtering.

    **Step 3: Extend config.py**
    Add `ClassificationConfig` Pydantic model with `confidence_threshold: float = 0.5` and `model: str = "gemini-2.5-flash"`. Add `classification: ClassificationConfig = ClassificationConfig()` field to `AppConfig`.

    **Step 4: Create classifier.py**
    - `create_genai_client() -> genai.Client`: reads `GEMINI_API_KEY` (or `GOOGLE_API_KEY`) from env, raises `SystemExit` with clear message if missing. Uses `python-dotenv` `load_dotenv()` before reading env.
    - `build_classification_prompt(email: EmailData, categories: list[CategoryConfig]) -> str`: assembles prompt with category names, descriptions, examples, and email fields (sender, subject, snippet). Explicitly instructs "assign 1 or 2 categories maximum" in prompt text (belt-and-suspenders with schema max_length).
    - `fuzzy_match_category(llm_category: str, valid_categories: list[str], threshold: int = 70) -> str | None`: uses `rapidfuzz.process.extractOne` with `fuzz.ratio` scorer. Returns best match name if score >= threshold, else None.
    - `classify_email(client: genai.Client, email: EmailData, categories: list[CategoryConfig], config: ClassificationConfig) -> ClassificationResult`: calls `client.models.generate_content` with `response_schema=ClassificationResponse`, `temperature=0.1`, `response_mime_type="application/json"`. Parses response, applies fuzzy matching to each returned category name, filters by confidence threshold, sets `is_ambiguous=True` if no categories survive filtering.

    **Important notes:**
    - Use `google.genai` (not `google.generativeai`) -- the new official SDK per RESEARCH.md
    - Pydantic models for LLM schema go in models.py (ClassificationResponse, CategoryClassification)
    - Internal result dataclass (ClassificationResult) also in models.py
    - System instruction: "You are an email classifier. Assign each email to 1-2 categories from the provided list. Be precise with confidence scores."
    - Thread context: per RESEARCH.md discretion recommendation, do NOT include thread context -- subject+sender+snippet is sufficient
