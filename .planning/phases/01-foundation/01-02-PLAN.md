<task type="auto">
  <name>Task 2: OAuth2 authentication, token persistence, and Gmail service</name>
  <files>src/email_triage/auth.py, tests/test_auth.py</files>
  <action>
**auth.py** — OAuth2 authentication module:

Constants:
- `SCOPES = ["https://www.googleapis.com/auth/gmail.modify"]` — single scope covers read + label + send (avoid scope mismatch pitfall from RESEARCH.md).
- `DEFAULT_TOKEN_PATH = "credentials/token.json"`
- `DEFAULT_CREDENTIALS_PATH = "credentials/credentials.json"`

`authenticate(credentials_path: str = DEFAULT_CREDENTIALS_PATH, token_path: str = DEFAULT_TOKEN_PATH) -> Credentials`:

1. **Load existing token** — if `token_path` exists, load with `Credentials.from_authorized_user_file(token_path, SCOPES)`. Print info: "Loading saved credentials..."
2. **Check validity** — if `creds` exists and `creds.valid`, return immediately. Print success: "Authenticated successfully."
3. **Auto-refresh** — if `creds` exists, `creds.expired`, and `creds.refresh_token`:
   - Print info: "Token expired, refreshing..."
   - Call `creds.refresh(Request())`
   - Save refreshed token to `token_path` (overwrite)
   - Set file permissions to 0o600 (pitfall #6 from RESEARCH.md)
   - Print success: "Token refreshed successfully."
4. **First-run interactive flow** — if no valid creds:
   - Check `credentials_path` exists, if not: `print_error("credentials.json not found at {path}", suggestion="Download it from Google Cloud Console -> APIs & Services -> Credentials -> OAuth 2.0 Client IDs -> Download JSON")` then `sys.exit(1)`.
   - Print step-by-step guidance (verbose, per user decision):
     - Step 1/3: "Opening browser for Google authorization..."
     - Step 2/3: "Sign in with your Google account and grant access to Gmail"
     - Step 3/3: "Waiting for authorization callback..."
   - Create `InstalledAppFlow.from_client_secrets_file(credentials_path, SCOPES)`
   - Call `flow.run_local_server(port=0, open_browser=True)` — this auto-opens browser and prints URL as fallback if browser fails (per user decision and pitfall #5 from RESEARCH.md).
   - Save token to `token_path` with permissions 0o600.
   - Ensure `credentials/` directory exists before writing (`os.makedirs` with `exist_ok=True`).
   - Print success: "Authorization complete! Token saved to {token_path}"
   - Print info: "Note: Your OAuth2 consent screen must be 'Published' (not 'Testing') for the token to persist beyond 7 days. See: https://console.cloud.google.com/apis/credentials/consent" (pitfall #1 from RESEARCH.md).

`get_gmail_service(creds: Credentials)`:
- `return build("gmail", "v1", credentials=creds)`

Use `unittest.mock.patch` for Google library mocks. Use `tmp_path` for file operations.
